# AsterCC 0.3 roadmap

After the provider layer is verified on the target firmware:

1. Runtime class discovery for the native layout objects.
2. AsterCC-owned `CCUILayoutRect` map.
3. 4-column x 8-row grid.
4. Drag/drop with collision resolution.
5. Resize handles using a shadow layout first; commit only on release.
6. Multi-page order.
7. Add Control sheet based on discoverable module definitions.
8. Remove controls by editing the provider list.
9. Transactional save + rollback if Control Center reports an invalid configuration.
10. iPad-specific geometry profile.
